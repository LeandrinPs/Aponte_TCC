# Ilustrações locais do Aponte

Os 13 SVGs desta pasta são desenhos vetoriais originais, criados para o Aponte
em 23/11/2026 a partir de formas geométricas. Não incorporam fotografias, fontes,
logotipos ou conteúdo do Google Maps, de bancos de imagens ou de terceiros.
São ilustrações de culinária; não representam os pratos ou ambientes reais de
qualquer estabelecimento.

Estes **13 SVGs novos**, exclusivamente, são disponibilizados sob
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
É permitido copiar, modificar e distribuir, inclusive comercialmente, sem
atribuição obrigatória. Esta declaração não altera a licença dos demais arquivos
do projeto. Origem de todos os arquivos: desenho original para este projeto.

Dimensões: 800 × 480 (5:3), escaláveis, sem scripts ou referências externas.
Os componentes mantêm suas dimensões e `object-fit` existentes. A identificação
“Imagem ilustrativa” é adicionada pela interface, inclusive para leitores de tela.
A escolha está centralizada em `Aponte.ilustracao(categoria)` e não é aleatória.
